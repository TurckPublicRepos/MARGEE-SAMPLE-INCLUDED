## MARGEE Sample Program

This project is the official sample program included with the **MARGEE** extension.

### Purpose
The sample demonstrates the structure and usage of a typical MARGEE-based HMI (Human-Machine Interface) project. It provides example code, HMI screens, and styling to help users get started quickly with their own MARGEE applications.

### Contents
- Example HMI screens and elements
- TypeScript and CSS files for custom elements
- Sample project structure for reference

For more information about the MARGEE extension, please refer to the official documentation or the extension's marketplace page.
